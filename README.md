# DinDin 
Um app de controle financeiro com interface de chat. Você fala, ele entende — e te ajuda a cuidar do seu dinheiro como um verdadeiro parceiro de bolso.

## Tecnologias e ferramentas
- React
- Tailwind CSS
- JavaScript
- Lucide (Ícones)
- Figma (Design)

## Funcionalidades principais
- Cadastro de entradas e gastos com texto natural
- Visualização do saldo atual em tempo real
- Filtros por categoria
